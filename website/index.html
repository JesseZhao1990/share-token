HOW IT WORKS

每一步，都有明确的边界。

Your Hub. Your devices. Explicit permissions.

  1. 01

    部署你的 Hub

    在个人服务器或可访问的自有机器上部署 Hub，配置 HTTPS/WSS 与持久数据目录。

    Run a Hub on infrastructure you control, with HTTPS/WSS and persistent storage.

  2. 02

    连接并授权

    参与者连接同一空间。加入空间后，提供方仍需明确授权设备、模型和额度规则。

    Pair your devices, then explicitly authorize access and usage policies. Joining alone grants no source access.

  3. 03

    在本机完成项目

    Codex 经本地 Bridge 使用配置的来源。本地工具在使用方运行；提供方的分享进程需要在线。

    Codex uses the local bridge. Tools execute locally; the provider and its sharing process must remain online.

从模拟环境开始

源码包含无需真实账户的模拟 Hub 与测试。实际模型接入需要各自授权；请先确认所使用服务允许相应用途。默认配置不包含账户、连接空间或线上凭据。

Start with the mock demo, which needs no real model account. Configure only upstream services you are authorized to use. No account or hosted space is included.

HTTPS/WSS 保护传输；当前 Hub 与 Relay 会在内存中处理请求内容，并非端到端加密。The Hub and relay process payloads in memory; transport is not end-to-end encrypted.
