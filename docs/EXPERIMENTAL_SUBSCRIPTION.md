# 实验订阅适配

开源版默认只运行模拟来源。`MockAdapter` 返回合成的 Responses/SSE 数据，用于检查 Hub、Relay、本地 Bridge、授权、撤销和结果处理，不调用真实模型，也不能完成真实编程任务。`HttpAdapter` 是自备端点的协议测试适配，尚未完成生产 API 兼容验收。

个人订阅适配源码保留在 `packages/upstream/subscription.ts`，属于默认关闭的实验能力。发布源码和启用技术开关都不代表获得任何上游授权；本项目不授予个人订阅的转售、跨人使用或共享权利。使用者必须自行确认账户适用条款、组织授权和允许的用途，不能把凭据留在本机作为授权依据。

## 默认边界

没有显式开启实验开关时：

- 登录、退出、状态查询及桌面订阅初始化返回 `SHARE_EXPERIMENTAL_SUBSCRIPTION_DISABLED`。
- 账户检查不会创建独立登录目录、启动订阅 Codex 进程或读取订阅凭据。
- 订阅适配器不会读取账户状态、额度或发送推理请求。
- 桌面端默认选择模拟来源；订阅来源不可用于启动本机会话。
- 恢复旧订阅配置不会自动恢复共享。模拟 Demo 不需要此开关。

这些限制同时位于 CLI、桌面主进程、工作进程、账户管理和推理适配器中。Hub、远程请求、JSON 配置和界面输入不能开启开关。

## 受控实验

仅在已经确认适用授权的个人环境中，操作者可以为该进程显式设置：

```sh
SHARE_TOKEN_ENABLE_EXPERIMENTAL_SUBSCRIPTION=1 npm run desktop
```

CLI 的订阅命令也要求同一开关，例如：

```sh
SHARE_TOKEN_ENABLE_EXPERIMENTAL_SUBSCRIPTION=1 node dist/apps/cli/index.js subscription-status --codex-home /absolute/path/to/new-isolated-account
```

只有严格等于字符串 `1` 才会启用。`true`、`yes`、`01`、带空格的值以及未设置都会保持关闭。桌面主进程会把这个开关单独传给工作进程；其他 `SHARE_TOKEN_*` 环境变量仍被清理。正式发布流程不得设置该开关。

账户目录必须是本应用专用的新目录，不能指向现有 `~/.codex` 或当前 `CODEX_HOME`。实验订阅账户管理使用指定的 Codex CLI 版本；模型、额度和登录能力会随上游变化。当前代码不构成真实共享、可靠性或兼容性验收证明。

停止实验时，退出应用并移除环境变量；下次启动重新恢复默认关闭。若要退出实验登录，应在开关仍开启时执行订阅退出操作，再关闭进程和开关。账户材料始终保存在个人运行目录，不应复制到仓库、构建产物或 CI。

## 测试边界

订阅回归测试仅显式启用合成夹具：假 Codex 程序、注入的 HTTP/SSE 传输及本机测试 Hub。默认关闭测试验证没有账户检查、登录子进程、凭据目录、上游传输或 Hub 写入。测试不会用真实账户或调用真实上游。
